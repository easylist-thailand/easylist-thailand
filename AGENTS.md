# AGENTS.md

Guidance for AI coding agents working in this repository.

## Project overview

EasyList Thailand is an **Adblock Plus / uBlock Origin filter list** for Thai websites. It is not a traditional application — the main artifacts are plain-text filter lists:

- `categories/*.txt` — the **source of truth** for filter rules, organized by website category (common, game, news, etc.). Add new rules here.
- `subscription/easylist-thailand.txt` and `subscription/ublock.txt` — **generated files**. Never edit them directly; they are regenerated by Rake.
- `lib/easylist_generator.rb` — Ruby generator that concatenates category files into the subscription files.
- `assets/header.txt` — subscription header template (`%{version}` / `%{last_modified}` are formatted by the generator in Thai time, `+07:00`).

## Common tasks

```bash
bundle install              # install gems (rake, rubocop)
bundle exec rake            # regenerate subscription files (default task)
bundle exec rake clean      # delete the subscription directory
bundle exec rake rubocop    # lint Ruby code
```

## Key conventions

- **New filter rules go in `categories/*.txt`.** Pick the file matching the site's category; create a new category file only if none fits. Rules use standard Adblock syntax (e.g. `example.co.th##.ad-banner`).
- `categories/ublock.txt` is special: it is copied verbatim to `subscription/ublock.txt` and referenced via the `!#if ext_ublock` / `!#include` directives — excluded from the main concatenation in `lib/easylist_generator.rb`.
- **Ruby code** must pass RuboCop (`Style:*` cops are errors; `NewCops: disable` — see `.rubocop.yml`). Ruby style: no parens around method args where RuboCop style allows, `frozen_string_literal` magic comment required.
- **Commits must use [Gitmoji](https://gitmoji.carloscuesta.me/)** convention (e.g. `✨ Add filter rules for example.co.th`). Prefer [gitmoji-cli](https://github.com/carloscuesta/gitmoji-cli).
- The subscription header version is a timestamp generated at build time — do not hand-edit version/last-modified lines.

## Pitfalls

- Editing files under `subscription/` is pointless — `rake clean` deletes the whole directory and `rake` regenerates it.
- `vendor/bundle/` contains vendored gems — never modify or search it; RuboCop excludes it.
- Section headers as comments (e.g. `! Example`) are allowed in `categories/*.txt`; keep them meaningful and avoid unrelated blank-line churn to keep diffs minimal.
